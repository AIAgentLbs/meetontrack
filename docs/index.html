Your connections.
Your choice.

Recording and transcription run on your Mac. The interface is served at 127.0.0.1, and recordings and reports are saved in your user directory.

AI analysis in this beta uses your authenticated Codex CLI. Relevant conversation and repository excerpts may be sent to its configured AI service; the product does not promise that nothing leaves your Mac.

  • Repository access is read-only
  • No automatic clone, pull or fetch
  • External report delivery is optional

Fully offline AI, a choice of local transcription models and additional API/subscription connectors are planned, not included in v0.1.9.

Install the Mac beta.

One command after the prerequisites below. This is a technical beta, not a standalone notarized installer.

  • Apple Silicon and macOS 15+
  • Python 3.10+ and Apple Command Line Tools
  • Codex CLI installed and signed in
  • Google Chrome for PDF reports

Missing Apple tools? Run xcode-select --install and finish the system dialog first. Install Python with your usual package manager; see the Codex CLI setup guide for AI access.

Terminal
curl -fsSL https://meetontrack.com/install.sh | bash

Downloads v0.1.9, checks its SHA-256, and preserves private settings and recordings. You can inspect the script before running it. Quit Meeting Copilot Capture before installing over an existing copy.

  1. Approve Microphone and Screen & System Audio Recording for Meeting Copilot Capture in macOS settings.
  2. Run ~/.local/bin/meeting-copilot. The interface opens at http://127.0.0.1:43121.
  3. Select the relevant repositories, make a short test call, then check the saved audio and transcript.
Updating and troubleshooting

Automatic in-app updates are not enabled in this beta. The command installs the version explicitly pinned in the script. After a newer tested release is published and the script is updated, finish your call, quit Capture and run the same command.

If a prerequisite, download, checksum or helper compilation fails, the installer stops before replacing your current app. Existing app and web files are backed up during a reinstall. Recordings and delivery settings are not deleted.

If macOS blocks launch, review the downloaded app in Privacy & Security. Do not disable Gatekeeper globally. For audio permission problems, check the exact installed app, quit it and reopen it.

Install the Windows beta.

Windows 11 24H2+, x64. Ready-to-run package, no compilation or SDK. Requires an installed, signed-in Codex CLI. First installation downloads local speech models (about 1.5 GB).

Windows PowerShell
irm https://meetontrack.com/install.ps1 | iex

Unsigned technical beta. Do not disable SmartScreen or antivirus. Update: finish the call, close Capture and repeat the command. Recordings and settings are preserved.
