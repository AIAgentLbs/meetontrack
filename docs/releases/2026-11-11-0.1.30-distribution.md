# Public MeetOnTrack 0.1.30 distribution acceptance

Date: 2026-11-11. Downloadable technical beta, not a stable/hardware-certified
release. Owner approved building, publishing on GitHub Releases and updating
the website on 2026-11-11. The owner runs the in-app updates himself, so this
run did not install 0.1.30 on the owner's Mac, did not touch its running app or
config, did not trigger an update check there, and did not touch the Windows
machine. Same process as [0.1.29](2026-11-11-0.1.29-distribution.md); this
record lists what differs.

Contents: MEETONTRACK-146, the optional Twenty CRM integration (`4f9b43d` to
`cad03af`, described in [DELIVERY.md](../DELIVERY.md#twenty-crm-optional)):
read deal context before calls, one note per meeting after the call plus
`nextStep`, record choice when the match is unclear, a one-click stage
proposal, and a money/terms filter that is on by default. Off and invisible
until a CRM address and API key are saved. Nothing else user-facing ships:
`c7800dd`, `3d76105` and `fa691f0` change only `docs/`. Built from
`origin/main` `c7800ddf2999695e5cba25b97b5deec0be77a2e4`; CI and the Windows
packaged candidate acceptance passed on that revision.

As for 0.1.29, both releases were published as normal releases, not
pre-releases: `v0.1.30` is marked latest, `windows-v0.1.30` was published with
`--latest=false`.

## Explicit limits

No clean Mac and no audio hardware tests. Mac is ad-hoc signed and not
notarized; Windows is unsigned. The CRM integration was checked live once,
from the Mac, against the dogfood Twenty workspace; it has not been used from
Windows. Nothing installs by itself: the Install button or the installer
command starts it. Never restart an active recording to update.
