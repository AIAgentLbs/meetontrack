# Public MeetOnTrack 0.1.18 distribution acceptance

Date: 2026-11-02. Downloadable technical beta, not a stable/hardware-certified
release. Owner approved building, installing on the owner's Mac, publishing
the GitHub releases and updating the website on 2026-11-02. Same process as
[0.1.17](2026-10-26-0.1.17-distribution.md); this record lists what differs.

Contents: MEETONTRACK-105 (sign-in buttons for Codex, Claude Code and
Antigravity, Antigravity as an AI choice, a plain message when a provider
rejects its saved sign-in), MEETONTRACK-107 (analysis rebuilt automatically or
by a button when the AI failed during a meeting), and the review fixes.

## Known gaps

- The Windows machine still runs 0.1.13.
- MEETONTRACK-106: the Mac recorder still refuses Antigravity, so summaries
  and speaker names are unavailable with that choice; the Windows recorder is
  unchecked.
- MEETONTRACK-108: an abandoned Antigravity sign-in on macOS leaves agy open
  in its Terminal window.
- This Mac's GitHub token lacks `workflow` scope; the pin commit touching the
  workflow was pushed from the devserver. `gh auth refresh -s workflow` fixes it.
- The recorder repository keeps CI artifacts only briefly. A future native
  change needs a fresh recorder run; until then, 0.1.18's `capture/` files are
  the reference.

## Explicit limits

No clean Mac and no audio hardware tests. Real Antigravity sign-in and calls,
and an automatic rebuild after a real AI failure, were not exercised by the
release checks. Mac is ad-hoc signed and not notarized; Windows is unsigned.
No automatic installer is enabled. Never restart an active recording to
update.
