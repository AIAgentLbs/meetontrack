# Public MeetOnTrack 0.1.23 distribution acceptance

Date: 2026-11-09. Downloadable technical beta, not a stable/hardware-certified
release. Owner approved building, publishing for Mac and Windows, updating the
website, installing on the owner's Mac and closing the shipped tasks on
2026-11-09 ("Выпускаем 0.1.23 - да"). Same process as
[0.1.22](2026-11-08-0.1.22-distribution.md); this record lists what differs.

Contents: Windows - MEETONTRACK-133 (one assistant window: the launcher, the
tray and setup bring an open window forward, restoring it when minimized, or
open an Edge app window, falling back to the default browser; the page has the
website icon and reloads itself after an upgrade unless something was typed)
and MEETONTRACK-134 (`hidden_consoles.py` adds `CREATE_NO_WINDOW` to every
`Popen` unless the caller asks for its own console, so no terminal flashes for
`codex.cmd` and other console helpers). The web changes ship in both packages;
on the Mac they change nothing visible (the console patch is a no-op outside
Windows). Built from `origin/main` `0c65e7ae67d1b190bc756d2b247bf1f11747f37b`.

## Immutable package identity

Both packages embed application revision `0c65e7a`.

Mac: `capture/` is unchanged since 0.1.22. The Swift release build at
`0c65e7a` (same `-Xcxx -isystem` libc++ flag) was already up to date, so the
binary is the one built for 0.1.22; it was assembled as 0.1.23 (build 491).

lines of `f2py` and `numpy-config` (temporary build path, as in every build)
differ, and `web/hidden_consoles.py` and its test are added.

## Known gaps

- The one-window behavior and hidden console helpers were checked by unit
  tests, the Codex review and the packaged installation on a Windows CI
  runner, not on a real Windows desktop. The Windows machine still runs
  0.1.13.
- MEETONTRACK-131 (Windows still needs port 43121 free), MEETONTRACK-132
  (server aborts at interpreter shutdown on quit), MEETONTRACK-113,
  MEETONTRACK-118 and MEETONTRACK-85 remain.
- `swift-build` CI was not used; local Swift release build and 399 tests passed
  instead.
- This Mac's GitHub tokens lack `workflow` scope; the pin commit touching the
  workflow was pushed from the devserver (from a bundle of the same commits).

## Explicit limits

No clean Mac and no audio hardware tests. Mac is ad-hoc signed and not
notarized; Windows is unsigned. No automatic installer is enabled. Never
restart an active recording to update.
