# MeetOnTrack 0.1.21

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- MeetOnTrack is now one app with its own window. The assistant opens in the
  app instead of a browser tab, and the app runs its local service itself:
  Python and the web assistant are inside the app, and the separate background
  service of earlier versions is removed when you update. Closing the window
  keeps recording and analysis running from the menu bar; quitting the app
  stops both. Links to other sites (sign-in pages, Google Drive, PDFs) open in
  your browser. Reopen the assistant anytime with "Open MeetOnTrack
  assistant" ("Открыть помощник MeetOnTrack") in the recorder window or the
  menu-bar menu. Recordings, reports, models and settings are kept.
- On first launch the interface language is preselected from your Mac:
  Russian when macOS's first preferred language is Russian, English otherwise.
  Confirm it with one click or change it later in Settings.
- When the app quits, what its service started (AI tools, a browser printing
  a PDF, helpers) stops with it (MEETONTRACK-114), except a helper started in
  the first moment after the service starts (MEETONTRACK-126). The app uses only
  the service it started itself, never another program on the same port
  (MEETONTRACK-116).
- If the app restarts between sending a report by email and sending it to
  Telegram, the email is no longer sent again (MEETONTRACK-122). Each channel's
  result is kept on disk right after its send; a send whose result is unknown
  is never repeated without your confirmation.
- The report PDF now tries every installed browser in turn: Google Chrome,
  then Microsoft Edge, then Chromium. Only when none of them can print does
  the report go out as an HTML file (MEETONTRACK-123).
- Speaker corrections carry over to the final transcript in the last two rare
  cases: a meeting split from one recording whose boundary moved, and a revised
  final transcript whose lines moved. A line to check stays in the "check the
  speakers" ("проверьте спикеров") list in both (MEETONTRACK-121).

Everything from 0.1.20 is included. The Capture app is rebuilt from this
revision.

Known: an AI tool sign-in that is still open when you quit the app can stay
open (MEETONTRACK-124). If the update fails and the installer restores the
previous version, a retired setting removed from your settings file is not
put back; it was unused (MEETONTRACK-125). A final transcript that never
arrives stops being flagged after three days (MEETONTRACK-118). If you close
the Antigravity sign-in without finishing it, agy stays open in that Terminal
window; close the window yourself (MEETONTRACK-108).

Cloud AI receives the selected text context of the task it runs. Fact checking
sends the checked statement and matching knowledge base excerpts to the AI you
chose. Cloud speech recognition receives the audio only when you choose a cloud
engine. Google/SMTP integrations remain optional and off for new installations.
No usage-statistics feature is included.

## Update

Finish the call and quit Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Versions 0.1.12 and later show
this update in the app.

The installer verifies the pinned package checksum and preserves recordings and
settings. It removes the previous version's program files only after the new
app's own service answers; otherwise it puts the previous version back.
Automatic installation is deferred; version notifications are enabled by
default and can be disabled in Settings.
