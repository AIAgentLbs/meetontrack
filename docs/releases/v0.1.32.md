# MeetOnTrack 0.1.32

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- macOS keeps the Screen & System Audio Recording permission across updates
  (MEETONTRACK-155). Until now the app was signed ad hoc, so macOS treated
  every new version as a new app and asked again. From 0.1.32 every release is
  signed with the same MeetOnTrack certificate. After this update macOS asks
  one last time (it may also ask again for the microphone and calendar);
  allow it once, and later updates keep the permission. If the old entry
  stays in Privacy & Security > Screen & System Audio Recording and recording
  still fails, remove MeetOnTrack there and allow it again.
- The menu bar shows a new version: "Version X available - Install" on top of
  the MeetOnTrack menu, one notification per new version, and the install
  progress while it runs. Clicking Install starts the same checked installer
  as the button in the assistant (MEETONTRACK-156). A failed install offers
  Try again; a newer release after a failed one is offered again.
- Settings has its own Install button next to the release offer, with the
  install progress, even when the notice at the top was dismissed or muted;
  the Terminal command is folded below it (MEETONTRACK-156).
- Report delivery: two delivery libraries were updated to fix five published
  security advisories (oauthlib 4.0.1, pyasn1 0.6.5).

Everything from 0.1.31 is included. The Capture app is built from this
revision; its Swift sources changed since 0.1.31.

Known: whether every Zoom name is read correctly still depends on the screen
reading; speaker separation may need manual correction.

Cloud AI receives the selected text context of the task it runs. Fact checking
sends the checked statement to the AI you chose; knowledge base excerpts go
only to its call without web access. Cloud speech recognition receives the
audio only when you choose a cloud engine. Google/SMTP/CRM integrations remain
optional and off for new installations. No usage-statistics feature is
included.

## Update

On 0.1.26 to 0.1.31, use the Install button. Otherwise finish the call and quit
Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Versions 0.1.12 to 0.1.25 show
this update in the app but have no Install button yet; use the command.

The installer verifies the pinned package checksum and preserves recordings and
settings. It removes the previous version's program files only after the new
app's own service answers; otherwise it puts the previous version back.
Nothing installs by itself: the Install button or the command above starts
it. Version notifications are enabled by default and can be disabled in
Settings.
