  tray's "Open" should show the assistant in his default browser and Google
  sign-in should open there.
- The app's own window was not seen on the owner's Mac (screen locked); the
  Mac binary is the 0.1.24 build whose window was seen then.
- MEETONTRACK-138, MEETONTRACK-139, MEETONTRACK-131, MEETONTRACK-132,
  MEETONTRACK-113, MEETONTRACK-118 and MEETONTRACK-85 remain.
- `swift-build` CI ran on the built revision `36c1d53`; the Swift tests ran
  locally.
- This Mac's GitHub tokens lack `workflow` scope; the pin commit touching the
  workflow was pushed from the devserver (from a bundle of the same commits).

## Explicit limits

No clean Mac and no audio hardware tests. Mac is ad-hoc signed and not
notarized; Windows is unsigned. No automatic installer is enabled. Never
restart an active recording to update.
