# MeetOnTrack 0.1.34

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

The assistant is redesigned around one call: Home before it, the Call view
during it and the After view once it ends.

- Home (MEETONTRACK-161). Today's and tomorrow's calendar meetings, each with
  two or three lines of its memo and where they came from. When the calendar
  is not connected, there are no meetings or a memo is not ready yet, Home
  says so instead of showing an empty page.
- The app writes the memo itself (MEETONTRACK-164). For meetings today and
  tomorrow with people from outside your own mail domain, the AI you chose
  prepares the pre-call memo ahead of time from the sources you connected:
  local folders, past reports, earlier calendar meetings and the CRM. A
  button rebuilds it. Without a chosen AI, Home asks you to choose one.
- The Call view (MEETONTRACK-162). One feed with a single large hint, "heard"
  or "not heard" for each side of the call, hints that fade with the earlier
  ones in a drawer, a "question heard" state, and the transcript behind a
  toggle. Stop recording (Cmd+Shift+E) pauses at once and ends the recording
  for good after 30 seconds; Resume recording within those 30 seconds
  continues the same recording.
- The After view (MEETONTRACK-163). Before the report leaves you see who gets
  it on each channel, can edit the summary and next steps, hold it or send it
  now, and see the call checked against its memo. The report carries your
  edits and is sent 30 seconds after it appears or after your last change,
  unless you hold it.
- Calmer app chrome (MEETONTRACK-165): at most three controls in the top bar
  plus a menu, panels open over the page, one call status, Settings regrouped,
  keyboard order and border contrast fixed.
- When a call starts recording by itself without microphone access, the app
  says once that your voice is not being recorded; a click opens the
  Microphone settings. The call itself is still recorded.

Everything from 0.1.33 is included. The Capture app is built from this
revision; its Swift sources changed since 0.1.33 so that Stop and Resume work
for one call at a time. It is signed with the same MeetOnTrack certificate,
so macOS keeps its Screen & System Audio Recording permission.

Known: calendar attendee names do not reach the report yet, and there is no
preview of how recipients will see the report (MEETONTRACK-179, 180). Send
now does nothing on a report held for more than three days
(MEETONTRACK-178). Whether every Zoom name is read correctly still depends on
the screen reading; speaker separation may need manual correction.

Cloud AI receives the selected text context of the task it runs. The memo is
written from the meeting's calendar details and matching excerpts of the
sources you connected; the check after the call sends the transcript and the
memo. Both go only to the AI you chose, without web access. Fact checking
sends the checked statement to the AI you chose; knowledge base excerpts go
only to its call without web access. Cloud speech recognition receives the
audio only when you choose a cloud engine. Google/SMTP/CRM integrations remain
optional and off for new installations. No usage-statistics feature is
included.

## Update

On 0.1.26 to 0.1.33, use the Install button. Otherwise finish the call and quit
Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Versions 0.1.12 to 0.1.25 show
this update in the app but have no Install button yet; use the command.

The installer verifies the pinned package checksum and preserves recordings and
settings. It removes the previous version's program files only after the new
app's own service answers; otherwise it puts the previous version back.
Nothing installs by itself: the Install button or the command above starts
it. Version notifications are enabled by default and can be disabled in
Settings.
