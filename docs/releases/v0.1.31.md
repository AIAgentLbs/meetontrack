# MeetOnTrack 0.1.31

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- Live transcription follows a changed speech choice: picking another speech
  model restarts live transcription with it (MEETONTRACK-76). When the
  Parakeet live recognizer falls behind, it now waits instead of piling up
  audio, so a slow or stuck recognizer is noticed and recovered
  (MEETONTRACK-77).
- Speech settings keep the API key you are typing while a model downloads
  (MEETONTRACK-79), and a stored cloud key the provider rejects can now be
  replaced (MEETONTRACK-78).
- Cloud speech engines (AssemblyAI, OpenAI) link to the provider's own pricing
  page; the app shows no prices itself (MEETONTRACK-72). A failed
  transcription shows its reason instead of a code like "STTRuntime.Failure
  error 1" (MEETONTRACK-151).
- Antigravity works for the recorder's own tasks (summaries and speaker
  names) when it is your AI choice; it runs with commands and web access
  denied, in an empty folder (MEETONTRACK-106). Closing or timing out the
  Antigravity sign-in now also stops agy in its Terminal window
  (MEETONTRACK-108).
- Claude Code needs version 2.1.304 or later; an older one is shown as
  unavailable with a hint to update (MEETONTRACK-6).
- Ollama: Chinese, Japanese, Korean and emoji text is sized correctly for the
  model's context, so long transcripts are split into parts that fit
  (MEETONTRACK-8, MEETONTRACK-153); long chats keep the session rules and
  drop older meeting snapshots first (MEETONTRACK-50).
- Live translation: its status updates on screen when it changes, and "choose
  an AI" or "unavailable" stays visible until a translation actually works
  (MEETONTRACK-51, MEETONTRACK-52). A "translation" that only repeats the
  original line is no longer stored or shown, including ones saved by earlier
  versions (MEETONTRACK-64).
- Report delivery: older repaired reports keep their status and Send again
  button, and a resend still in progress at its deadline says it may not have
  arrived (MEETONTRACK-93). If the final transcript arrives late, the report
  that never went out is now sent automatically, and the waiting notice stays
  until then (MEETONTRACK-118).
- Zoom: speaker names that the screen reading cut short or garbled (for
  example mixed Cyrillic and Latin) are matched to the full name seen
  elsewhere in the same meeting (MEETONTRACK-91).
- Fact checking checks your knowledge base excerpts (Gmail, Drive, context
  folders) in a separate call without web access; the web search step
  receives only the statement (MEETONTRACK-128).
- Reading context from your repositories no longer runs commands that a
  repository's own git settings could define (hooks, filters, external diff
  tools, submodules) (MEETONTRACK-129).
- Better contrast in light and dark themes, and no text smaller than 11px
  (MEETONTRACK-22).

Everything from 0.1.30 is included. The Capture app is built from this
revision; its Swift sources changed since 0.1.30.

Known: whether every Zoom name is read correctly still depends on the screen
reading; speaker separation may need manual correction.

Cloud AI receives the selected text context of the task it runs. Fact checking
sends the checked statement to the AI you chose; knowledge base excerpts go
only to its call without web access. Cloud speech recognition receives the
audio only when you choose a cloud engine. Google/SMTP/CRM integrations remain
optional and off for new installations. No usage-statistics feature is
included.

## Update

On 0.1.26 to 0.1.30, use the Install button. Otherwise finish the call and quit
Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Versions 0.1.12 to 0.1.25 show
this update in the app but have no Install button yet; use the command.

The installer verifies the pinned package checksum and preserves recordings and
settings. It removes the previous version's program files only after the new
app's own service answers; otherwise it puts the previous version back.
Nothing installs by itself: the Install button or the command above starts
it. Version notifications are enabled by default and can be disabled in
Settings.
