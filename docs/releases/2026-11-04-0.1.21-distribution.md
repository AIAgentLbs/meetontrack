# Public MeetOnTrack 0.1.21 distribution acceptance

Date: 2026-11-04. Downloadable technical beta, not a stable/hardware-certified
release. Owner approved building, publishing for Mac and Windows, updating the
website and installing on the owner's Mac on 2026-11-04 ("0.1.21 согласен").
Same process as [0.1.20](2026-11-04-0.1.20-distribution.md); this record lists
what differs.

Contents: Mac - MEETONTRACK-109 (one app with its own window: Python and the
web payload inside the bundle, the app runs the local service itself and the
launchd agent is retired on update), MEETONTRACK-114 (what the service started
stops when the app quits), MEETONTRACK-116 (interface language preselected
from macOS). Mac and Windows - MEETONTRACK-121, -122, -123. Built from
`origin/main` `1d50bf29d1ed4cafc90af2530a4b1544d4e7edd9`.

## Immutable package identity

Both packages embed application revision `1d50bf2`.

Mac: the Swift app was rebuilt in release mode from `capture/` at `1d50bf2`
(LocalVQE and Sparkle reused from the published 0.1.20 archive, Python runtime
from a clean uv `cpython-3.12.13`) and assembled as 0.1.21 (build 471) in the

the numpy scripts (temporary build path, as in every build), the binary,

`capture/` differ and `web/test_parent_watch.py` is added. Against the
CI-composed candidate it differs only by line endings and the interpreter that
built the pyc/vendor files, as for 0.1.20.
