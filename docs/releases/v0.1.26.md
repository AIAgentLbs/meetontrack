# MeetOnTrack 0.1.26

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- Updates install from the app (MEETONTRACK-142). When a newer version is
  published, the header shows "Version X available" with an Install button.
  It quits Capture the way its Quit menu does, installs that exact release
  from GitHub with the official installer, which checks the package
  checksum, and reopens MeetOnTrack. During a recording the update waits
  until the recording ends; if Capture declines to quit, nothing is
  installed. If it fails, the old version keeps working and the notice offers
  Try again; the details are in `update.log`. The button arrives with this
  version, so updating to 0.1.26 itself still takes the command below.
- An automatic recording stops after the call even when the browser keeps a
  silent audio output open (MEETONTRACK-138). Such a recording ran to the
  duration limit; now an open output only postpones the stop by one more
  silence window (20 minutes by default).
- Quitting the app no longer ends the assistant's service with "Fatal Python
  error" in `server.log` (MEETONTRACK-132).
- Turning on email or Drive delivery no longer reports meetings from before
  it was turned on as overdue (MEETONTRACK-141).

Everything from 0.1.25 is included. The Capture app is rebuilt from this
revision.

Known: a final transcript that never arrives stops being flagged after three
days (MEETONTRACK-118). If you close the Antigravity sign-in without finishing
it, agy stays open in that Terminal window; close the window yourself
(MEETONTRACK-108).

Cloud AI receives the selected text context of the task it runs. Fact checking
sends the checked statement and matching knowledge base excerpts to the AI you
chose. Cloud speech recognition receives the audio only when you choose a cloud
engine. Google/SMTP integrations remain optional and off for new installations.
No usage-statistics feature is included.

## Update

Finish the call and quit Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Versions 0.1.12 to 0.1.25 show
this update in the app but have no Install button yet; use the command.

The installer verifies the pinned package checksum and preserves recordings and
settings. It removes the previous version's program files only after the new
app's own service answers; otherwise it puts the previous version back.
Nothing installs by itself: the Install button or the command above starts
it. Version notifications are enabled by default and can be disabled in
Settings.
