# Public MeetOnTrack 0.1.34 distribution acceptance

Date: 2026-11-22. Downloadable technical beta, not a stable/hardware-certified
release. Owner approved on 2026-11-22 publishing 0.1.34 for Mac and Windows with
the redesign (Home with the memo, the Call view, the After view), the website
updated in the same run. This run did not install 0.1.34 on the owner's Mac,
did not touch its running app or `~/.config/meeting-copilot`, sent no `record`
commands and did not touch the Windows machine. Same process as
[0.1.33](2026-11-20-0.1.33-distribution.md); this record lists what differs.

Contents: `redesign-call-flow` (`dd17f1d`) merged `--no-ff` into main
(`9f365e4`) as `7000034`: MEETONTRACK-165 (app chrome), MEETONTRACK-161 (Home),
MEETONTRACK-164 (the app writes the memo), MEETONTRACK-162 (Call view, Stop
and Resume with the new `record pause` verb in both recorders) and
MEETONTRACK-163 (After view, memo check), each reviewed by Codex and critiqued
on its branch. Then `194b48c`: the memo check item key uses SHA-256 instead of
SHA-1 (Semgrep blocking finding on main; the key is an item id, no stored keys
existed). User-facing summary in [v0.1.34](v0.1.34.md) and
[windows-v0.1.34](windows-v0.1.34.md). Built from `194b48c`.

## Explicit limits

No clean Mac and no audio hardware tests. Mac is signed with a self-signed
certificate and not notarized; Windows is unsigned. Nothing installs by
itself. Never restart an active recording to update.
