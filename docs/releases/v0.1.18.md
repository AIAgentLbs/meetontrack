# MeetOnTrack 0.1.18

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- Signing in to an AI tool no longer needs a command. When Codex, Claude Code
  or Antigravity is installed but signed out, or rejected its saved sign-in,
  Getting started and the red banner show "Sign in to <tool>" ("Войти в
  <tool>"). Codex and Claude Code open their sign-in in the browser;
  Antigravity opens it in a Terminal window. The app notices when the sign-in
  is done and checks the AI again. When a provider rejects its saved sign-in,
  the message now says so ("needs a new sign-in: it rejected the saved one")
  instead of showing the provider's raw error.
- Antigravity can now be chosen as the AI. It runs with its own strict
  settings: no files, no commands, web pages only for tasks that search the
  web. It cannot search Git repositories or read screenshots. The Capture
  app cannot use it yet for meeting summaries and speaker names
  (MEETONTRACK-106); these show as unavailable with that reason.
- If the AI fails during a meeting (for example, its sign-in expired), the
  meeting's analysis is no longer lost. Once the AI works again, MeetOnTrack
  builds the missing analysis from the stored transcript by itself, never
  while a call is being recorded. It retries after 5 minutes, then waits
  longer each time, up to 2 hours, and tries at once after Check AI. A past
  meeting in the archive also has a "Rebuild analysis" ("Построить разбор")
  button. Long meetings are analysed in parts of the same size as during the
  call, parts already analysed are not sent again, and a rebuild does not
  create a report or send email. If the transcript changes later (for
  example after retranscription), the button is offered again.
- Fixes found in review: Antigravity refuses to answer while its sign-in link
  still points to a previous Google account; a call waiting for another
  Antigravity call counts that wait against its own time limit.

Everything from 0.1.17 is included. The Capture app itself is unchanged from
0.1.16.

Known: if you close the Antigravity sign-in without finishing it, agy stays
open in that Terminal window; close the window yourself (MEETONTRACK-108).

Cloud AI receives the selected text context of the task it runs. Fact checking
sends the checked statement and matching knowledge base excerpts to the AI you
chose. Cloud speech recognition receives the audio only when you choose a cloud
engine. Google/SMTP integrations remain optional and off for new installations.
No usage-statistics feature is included.

## Update

Finish the call and quit Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Versions 0.1.12 and later show
this update in the app.

The installer verifies the pinned package checksum and preserves recordings and
settings. Automatic installation is deferred; version notifications are enabled
by default and can be disabled in Settings.
