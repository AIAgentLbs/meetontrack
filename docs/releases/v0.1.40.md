# MeetOnTrack 0.1.40

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- A recording no longer stops by itself while you are still talking when the
  other side's audio stops reaching the app in the middle of a call
  (MEETONTRACK-207). The app used to treat the silent call audio as the end of
  the call. Now the recording continues while live transcription still hears
  you speak, the call app still uses the microphone and still plays sound,
  for up to six times the silence-stop time in Settings (one hour with the
  default of 10 minutes). After the call, silence and room noise still end it
  as before. What the microphone records in that stretch is labelled as you
  instead of an unknown speaker, and the transcript header says since when no
  call audio has reached the recording, also in the Call view.
- When several people on a call come through as one voice, a person who
  introduces themselves later no longer renames everything said earlier on
  that voice (MEETONTRACK-206). Once the app sees from the call window that
  one voice carries several people, it names each line from what the window
  showed at that moment, in the live view, the final transcript and the
  report; a line with no usable picture stays unnamed.
- When the sources you connected mention the people in a meeting but give
  nothing to prepare from, Home says nothing was found instead of showing a
  failed memo (MEETONTRACK-201). If the meeting already had a memo, that memo
  stays. A reply from the AI that cannot be read is still retried once.

Everything from 0.1.39 is included. The Capture app is rebuilt from this
revision and signed with the same MeetOnTrack certificate, so macOS keeps its
Screen & System Audio Recording permission.

Known: the guard against stopping early works only with live transcription
on; without it, a call whose audio goes silent can still end the recording
early. Why the call audio went silent in the first place is not yet known
(MEETONTRACK-209). One person can still appear several times in the
participant list under slightly different spellings of their name
(MEETONTRACK-208). A few calendar sign-in states are still worded loosely
(MEETONTRACK-184). After a reinstall Capture may not ask again for a
permission that macOS lost; check Microphone and Screen & System Audio
Recording in System Settings if the app says a side is not being recorded
(MEETONTRACK-185). Calendar attendee names do not reach the report yet, and
there is no preview of how recipients will see the report (MEETONTRACK-179,
180). Send now does nothing on a report held for more than three days
(MEETONTRACK-178). Speaker separation may need manual correction.

The calendar is read from Google with your own sign-in and stays on this
Mac. Cloud AI receives the selected text context of the task it runs: the
memo is written from the meeting's calendar details and matching excerpts of
the sources you connected, and the check after the call sends the transcript
and the memo, only to the AI you chose, without web access. Cloud speech
recognition receives the audio only when you choose a cloud engine.
Google/SMTP/CRM integrations remain optional and off for new installations.
No usage-statistics feature is included.

## Update

On 0.1.26 to 0.1.39, use the Install button. Otherwise finish the call and quit
Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Versions 0.1.12 to 0.1.25 show
this update in the app but have no Install button yet; use the command.

The installer verifies the pinned package checksum and preserves recordings and
settings. It removes the previous version's program files only after the new
app's own service answers; otherwise it puts the previous version back.
Nothing installs by itself: the Install button or the command above starts
it. Version notifications are enabled by default and can be disabled in
Settings. Do not update during a recording.
