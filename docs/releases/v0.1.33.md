# MeetOnTrack 0.1.33

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- The assistant is fast again with many stored meetings (MEETONTRACK-160).
  Since 0.1.31 every refresh of the assistant window matched the speaker
  names read from the Zoom screen against every stored meeting, so with a few
  thousand stored screen readings the window answered only after 20-30
  seconds. Now each meeting and speaker is matched once and a refresh takes
  well under a second.
- Call memo before and after the call (MEETONTRACK-159). The Preparation tab
  shows the full pre-call memo as plain text and an "Open memo document" link
  when the memo has one. Preparation notes named `*-prep.md` are picked up
  when they are dated by `call_date:`, `date:` or the date at the start of the
  file name. Between calls the tab lists today's and tomorrow's calendar
  meetings with their memo, or "No memo". In the library a meeting shows its
  memo and, when its report was delivered to Google Drive, links to the Drive
  folder and the report files. The screens keep their current layout; the
  redesigned memo screens come in a later release.

Everything from 0.1.32 is included. The Capture app's Swift sources are
unchanged since 0.1.32; the app is assembled from this revision and signed
with the same MeetOnTrack certificate, so macOS keeps its Screen & System
Audio Recording permission from 0.1.32.

Known: whether every Zoom name is read correctly still depends on the screen
reading; speaker separation may need manual correction.

Cloud AI receives the selected text context of the task it runs. Fact checking
sends the checked statement to the AI you chose; knowledge base excerpts go
only to its call without web access. Cloud speech recognition receives the
audio only when you choose a cloud engine. Google/SMTP/CRM integrations remain
optional and off for new installations. No usage-statistics feature is
included.

## Update

On 0.1.26 to 0.1.32, use the Install button. Otherwise finish the call and quit
Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Versions 0.1.12 to 0.1.25 show
this update in the app but have no Install button yet; use the command.

The installer verifies the pinned package checksum and preserves recordings and
settings. It removes the previous version's program files only after the new
app's own service answers; otherwise it puts the previous version back.
Nothing installs by itself: the Install button or the command above starts
it. Version notifications are enabled by default and can be disabled in
Settings.
