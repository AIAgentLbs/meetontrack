# MeetOnTrack 0.1.36

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- Home shows your calendar again when Google is connected through a named
  Google profile (MEETONTRACK-186). In 0.1.35 the calendar used the
  Google command-line tool's default profile instead of the personal or work
  profile chosen in Settings, so Home said the calendar could not be read and
  showed no meetings. It now reads through the chosen profile, the same one
  reports are delivered with; if that profile's tool is missing, Home says so
  instead of reading another account. Without a chosen profile Home offers to
  connect Google, as before. The app's own Google sign-in from 0.1.35 is
  unchanged.

Everything from 0.1.35 is included. The Capture app's Swift sources are
unchanged since 0.1.34; the app is assembled from this revision and signed
with the same MeetOnTrack certificate, so macOS keeps its Screen & System
Audio Recording permission.

Known: a few calendar sign-in states are still worded loosely, for example a
hint about the command-line tool when no sign-in is connected
(MEETONTRACK-184). After a reinstall Capture may not ask again for a
permission that macOS lost and may then not start recording by itself; check
Microphone and Screen & System Audio Recording in System Settings
(MEETONTRACK-185). Calendar attendee names do not reach the report yet, and
there is no preview of how recipients will see the report (MEETONTRACK-179,
180). Send now does nothing on a report held for more than three days
(MEETONTRACK-178). Speaker separation may need manual correction.

The calendar is read from Google with your own sign-in and stays on this
Mac. Cloud AI receives the selected text context of the task it runs: the
memo is written from the meeting's calendar details and matching excerpts of
the sources you connected, and the check after the call sends the transcript
and the memo, only to the AI you chose, without web access. Cloud speech
recognition receives the audio only when you choose a cloud engine.
Google/SMTP/CRM integrations remain optional and off for new installations.
No usage-statistics feature is included.

## Update

On 0.1.26 to 0.1.35, use the Install button. Otherwise finish the call and quit
Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Versions 0.1.12 to 0.1.25 show
this update in the app but have no Install button yet; use the command.

The installer verifies the pinned package checksum and preserves recordings and
settings. It removes the previous version's program files only after the new
app's own service answers; otherwise it puts the previous version back.
Nothing installs by itself: the Install button or the command above starts
it. Version notifications are enabled by default and can be disabled in
Settings.
