# Public MeetOnTrack 0.1.33 distribution acceptance

Date: 2026-11-20. Downloadable technical beta, not a stable/hardware-certified
release. Owner approved on 2026-11-20 releasing 0.1.33 for Mac and Windows with
the speed fix and the memo data layer, the website updated in the same run, the
new screens not included. This run did not install 0.1.33 on the owner's Mac,
did not touch its running app or `~/.config/meeting-copilot`, and did not touch
the Windows machine. Same process as
[0.1.32](2026-11-18-0.1.32-distribution.md); this record lists what differs.

Contents (`72dad98..06cd585`): MEETONTRACK-160 (`06cd585`, `/api/state` fast
again) and MEETONTRACK-159 (`fe55bf1`, call memo data layer, agenda API, Drive
links, plain rendering); both were reviewed by Codex before this run (159:
three rounds, no P0/P1). User-facing summary in [v0.1.33](v0.1.33.md) and
[windows-v0.1.33](windows-v0.1.33.md). Built from `06cd585`.

## Known gaps

- MEETONTRACK-157, MEETONTRACK-154 and MEETONTRACK-127 remain open. The visual
  rebuild of the memo screens was not part of this release.
- Permission persistence across an update from 0.1.32 (155) is proven by the
  signature only; this is the first update where it can be observed.

## Explicit limits

No clean Mac and no audio hardware tests. Mac is signed with a self-signed
certificate and not notarized; Windows is unsigned. Nothing installs by
itself. Never restart an active recording to update.
