# MeetOnTrack 0.1.19

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- Meeting reports are now sent only from the final transcript. The quick
  transcript you see during the call is never sent. When a call ends, the
  report waits until the recorder has finished the final transcript of the
  whole call, then it is made and sent once. Automatic retries print a report
  made earlier from the quick transcript again from the final one before
  sending it. "Send again" ("Отправить снова") never sends a report made from
  the quick transcript; it waits until the report has been made again.
- If the final transcript is still missing an hour after the call, the
  meeting and the delivery header say so ("waits for the final transcript",
  "ждет итоговую расшифровку") and ask you to check that the recorder is
  running. Nothing is sent from the quick transcript; the report goes out by
  itself once the final transcript arrives, if that happens within three days
  of the call. A final transcript that arrives later makes the report, which
  is then sent only when you ask (MEETONTRACK-118).
- A recording split into several meetings now gives each meeting its own
  part of the final transcript, so each of them gets its report.
- Speakers you correct during the call carry over to the final transcript.
  Before, a correction made before the final transcript arrived kept the final
  transcript from being applied, and that report was never sent. Now the final
  transcript is always applied and each correction moves to the lines spoken
  at the same time. If some corrections cannot be placed with confidence, the
  meeting asks you to check the speakers ("check the speakers", "проверьте
  спикеров") and names how many lines.
- Fixes found in review: a report whose text changed after it was printed
  (for example after a late fact check) is printed again instead of waiting
  forever; a send whose result is unknown is never repeated without your
  confirmation.

Everything from 0.1.18 is included. The Capture app itself is unchanged from
0.1.16.

Known: a few rare cases of carrying speaker corrections are still open
(MEETONTRACK-119), and a final transcript that never arrives stops being
flagged after three days. If you close the Antigravity
sign-in without finishing it, agy stays open in that Terminal window; close
the window yourself (MEETONTRACK-108).

Cloud AI receives the selected text context of the task it runs. Fact checking
sends the checked statement and matching knowledge base excerpts to the AI you
chose. Cloud speech recognition receives the audio only when you choose a cloud
engine. Google/SMTP integrations remain optional and off for new installations.
No usage-statistics feature is included.

## Update

Finish the call and quit Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Versions 0.1.12 and later show
this update in the app.

The installer verifies the pinned package checksum and preserves recordings and
settings. Automatic installation is deferred; version notifications are enabled
by default and can be disabled in Settings.
