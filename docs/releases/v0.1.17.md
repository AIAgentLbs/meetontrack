# MeetOnTrack 0.1.17

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- Updating no longer leaves extra copies of the app behind. Before, every
  update kept the previous version as "Meeting Copilot Capture.backup-..." in
  Applications, so Launchpad and Spotlight showed several MeetOnTrack icons.
  This update moves the copies left by earlier updates to the Trash; you can
  empty the Trash or put them back. If an update fails halfway, the previous
  version is put back as before.
- When the AI service is briefly overloaded, MeetOnTrack no longer says that
  your AI account limit is reached. It now says: "The AI service is busy and
  turned the request away for now. This is not your plan limit. Retry in a
  minute." ("Сервис ИИ сейчас перегружен и временно отклоняет запросы. Это не
  лимит вашего тарифа. Повторите через минуту." in Russian). The limit message
  appears only when the plan limit or credit is really used up.
- In the meeting report, the time of every phrase and every screenshot is
  your local time, the same as in the report header. Before, they were shown
  in UTC and could differ from the header by an hour or more. A meeting
  started with "Start new meeting" ("Начать новую встречу") is also titled
  with your local time.
- Two calls in one recording are now two meetings. Some call apps keep the
  microphone on between calls, so the next call continued the same recording
  and both ended up in one meeting and one report. Now a new meeting starts
  when the other side goes silent for at least 75 seconds right after
  goodbyes ("до свидания", "пока", "bye" and similar) and the conversation
  then continues. Calls in other languages are not split by themselves; use
  "Start new meeting" for them.
- Ordinary phrases such as "I'm sure" or "I'm going" are no longer taken as
  someone introducing themselves, so words like "sure" no longer appear as a
  participant's name.

Everything from 0.1.16 is included. The Capture app itself is unchanged from
0.1.16.

Cloud AI receives the selected text context of the task it runs. Fact checking
sends the checked statement and matching knowledge base excerpts to the AI you
chose. Cloud speech recognition receives the audio only when you choose a cloud
engine. Google/SMTP integrations remain optional and off for new installations.
No usage-statistics feature is included.

## Update

Finish the call and quit Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Versions 0.1.12 and later show
this update in the app.

The installer verifies the pinned package checksum and preserves recordings and
settings. Automatic installation is deferred; version notifications are enabled
by default and can be disabled in Settings.
