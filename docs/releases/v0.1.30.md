# MeetOnTrack 0.1.30

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- Optional Twenty CRM integration (MEETONTRACK-146). In Settings → Report
  storage and delivery → Twenty CRM, enter the CRM address and an API key; the
  key is kept in Keychain. Until both are saved, nothing about the CRM appears
  in the app.
  - Before and during a call the AI sees the attendees' CRM records: person,
    company, open deals (stage, next step, close date, never the amount) and
    the last note titles. They stay in memory for 10 minutes and are not saved
    with the recording.
  - After the call one note per meeting goes to the matched open deal, company
    or person: decisions, agreements and open questions, not the transcript.
    The deal's `nextStep` is set from the agreements when the deal has that
    text field.
  - When the record is not clear (several deals, no match), the report asks
    you to choose one; nothing is written before that, and the choice is
    remembered for the same attendee, company domain or recurring meeting.
  - A stage change is only proposed ("Move to X") from your workspace's own
    stages and happens only on that click.
  - Amounts, prices, payment, contract and licence terms are left out of the
    note by default; a switch in the CRM settings turns this off. The note
    says how many lines were withheld.

Everything from 0.1.29 is included. The Capture app is built from this
revision; its Swift sources are unchanged since 0.1.29.

Known: a final transcript that never arrives stops being flagged after three
days (MEETONTRACK-118). If you close the Antigravity sign-in without finishing
it, agy stays open in that Terminal window; close the window yourself
(MEETONTRACK-108).

Cloud AI receives the selected text context of the task it runs. Fact checking
sends the checked statement and matching knowledge base excerpts to the AI you
chose. Cloud speech recognition receives the audio only when you choose a cloud
engine. Google/SMTP/CRM integrations remain optional and off for new
installations; the CRM receives only the meeting note described above. No
usage-statistics feature is included.

## Update

On 0.1.26 to 0.1.29, use the Install button. Otherwise finish the call and quit
Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Versions 0.1.12 to 0.1.25 show
this update in the app but have no Install button yet; use the command.

The installer verifies the pinned package checksum and preserves recordings and
settings. It removes the previous version's program files only after the new
app's own service answers; otherwise it puts the previous version back.
Nothing installs by itself: the Install button or the command above starts
it. Version notifications are enabled by default and can be disabled in
Settings.
