# Public MeetOnTrack 0.1.32 distribution acceptance

Date: 2026-11-18. Downloadable technical beta, not a stable/hardware-certified
release. Owner approved building, publishing on GitHub Releases, updating the
website and closing the tasks on 2026-11-18, provided the full tests and the
Codex review had no P0/P1 left. The owner runs the in-app updates himself, so
this run did not install 0.1.32 on the owner's Mac, did not touch its running
app or config, and did not touch the Windows machine. Same process as
[0.1.31](2026-11-14-0.1.31-distribution.md); this record lists what differs.

Contents (`29b1221..107f2c7`): MEETONTRACK-155 (stable self-signed Mac

the Windows "Open MeetOnTrack assistant" button (`062e2d4`), and the

[windows-v0.1.32](windows-v0.1.32.md). Built from `107f2c7`.

## Signing (MEETONTRACK-155)

One self-signed code signing certificate (CN "MeetOnTrack Code Signing",
SHA-1 `A61D086120BF9A899DCCE6E59B9F05B4A3725136`, valid to 2056) was created
with OpenSSL; its PKCS#12 and password live only in Vault as "MeetOnTrack
macOS self-signed code signing" (read back and byte-compared after storing).
`scripts/with-signing-identity.sh` imports it into a throwaway keychain that
is on the user search list only while the wrapped build runs, under a per-user
lock, and verifies the search list is restored. Assembly and packaging sign
innermost first and set the requirement in
`capture/Packaging/designated-requirement.txt`. On the built app
`codesign -d -r-` shows `designated => identifier
"com.aiagentlbs.meetingcopilot.capture" and certificate leaf =
H"a61d086120bf9a899dcce6e59b9f05b4a3725136"`; `check_macos_candidate.py`
checks this on the installed app and rejects the ad-hoc 0.1.31 app. A small
binary signed the same way runs on this Mac although the certificate is not
trusted. That the grant survives a later update has not been observed on a Mac
yet (needs the next signed release).

  Pillow; Homebrew Python 3.15 has no Pillow, so 4 image tests error there).
  Script tests (installer, branding incl. the new signing test, deploy, window

  libc++ `-isystem` flag).
- `check_macos_candidate.py` on the exact archive: passed, including the
  designated requirement.
- Windows acceptance against the draft asset,
  [run 44340478810](https://github.com/AIAgentLbs/meetontrack/actions/runs/44340478810),
  passed (build and installer jobs).
- Codex (`gpt-6.1-sol`, xhigh): round 1 on the full range found no P0/P1 and
  one P2 (empty search-list snapshot broke cleanup), fixed in `0e29c8d`. Round
  2 on the signing fixes found 2 P1 in the build wrapper (concurrent runs drop
