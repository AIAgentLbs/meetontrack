# MeetOnTrack 0.1.20

Technical beta for Apple Silicon with macOS 15+. Windows is a separate package.

- A meeting report is no longer lost when its PDF cannot be made. The PDF is
  printed by Google Chrome; when Chrome is missing, Microsoft Edge or Chromium
  prints it. If that browser cannot make the PDF, the report still goes out
  by email and Telegram as a single HTML file with a short note. The meeting
  and the delivery header say "The PDF was not created" ("PDF не создан"), and the
  app tries the PDF again every 30 minutes. Google Drive, if you turned it on,
  waits for the PDF and then receives the report with its PDF and images;
  email and Telegram are not sent again. A PDF made more than three days
  after the call goes to Drive only when you ask. Only the final transcript is
  ever sent, as in 0.1.19.
- "Send again" ("Отправить снова") and the automatic retries also work for a
  report that has only the HTML file.
- Speakers you correct during the call carry over to the final transcript in
  more cases: when the final transcript joins a corrected line with its
  neighbour, in meetings split from one recording, and when a corrected part
  of a line is small. Names you still have to place, and lines still to check,
  stay in the "check the speakers" ("проверьте спикеров") list until you deal
  with them, also after the final transcript is revised. English translations
  of unchanged lines are kept.

Everything from 0.1.19 is included. The Capture app itself is unchanged from
0.1.16.

Known: two rarer cases of carrying speaker corrections remain, in split
meetings whose boundary moved and in a revised final transcript whose lines
moved (MEETONTRACK-121). If the app restarts between sending the email and
sending to Telegram, the email can be sent again (MEETONTRACK-122). A final
transcript that never arrives stops being flagged after three days
(MEETONTRACK-118). If you close the Antigravity sign-in without finishing it,
agy stays open in that Terminal window; close the window yourself
(MEETONTRACK-108).

Cloud AI receives the selected text context of the task it runs. Fact checking
sends the checked statement and matching knowledge base excerpts to the AI you
chose. Cloud speech recognition receives the audio only when you choose a cloud
engine. Google/SMTP integrations remain optional and off for new installations.
No usage-statistics feature is included.

## Update

Finish the call and quit Capture, then run:

```sh
curl -fsSL https://meetontrack.com/install.sh | bash
```

Versions 0.1.10 and 0.1.11 do not show this update in the app: the
project's GitHub address changed, and those versions reject release pages at
the new address. Run the command above once. Versions 0.1.12 and later show
this update in the app.

The installer verifies the pinned package checksum and preserves recordings and
settings. Automatic installation is deferred; version notifications are enabled
by default and can be disabled in Settings.
