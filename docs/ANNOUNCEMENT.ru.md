# Short announcement draft

MeetOnTrack by aiagentlbs.com - помощник для рабочих созвонов.

- Записывает и расшифровывает разговоры.
- Выделяет вопросы, риски, решения и договоренности.
- Позволяет задавать AI вопросы по ходу встречи.
- Сохраняет записи, стенограммы и заметки в одном месте.

Локальная расшифровка, AI-помощник через ваш аккаунт Codex. Ранняя версия для macOS.
