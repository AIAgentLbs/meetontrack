Подключения —
на ваш выбор.

Запись и расшифровка работают на Mac. Интерфейс доступен по 127.0.0.1, аудио и отчёты сохраняются в вашей пользовательской папке.

AI-анализ в этой beta использует авторизованный Codex CLI. Нужные фрагменты разговора и репозиториев могут передаваться его AI-сервису. Обещания «ничего не покидает Mac» здесь нет.

  • Доступ к репозиториям только для чтения
  • Без автоматических clone, pull и fetch
  • Внешняя доставка отчётов — по выбору

Полностью автономный AI, выбор локальных моделей расшифровки и дополнительные подключения через ключ или подписку запланированы, но не входят в v0.1.9.

Установите beta для Mac.

Одна команда после подготовки зависимостей. Это техническая beta, пока не самостоятельный notarized-установщик.

  • Apple Silicon и macOS 15+
  • Python 3.10+ и Apple Command Line Tools
  • Установленный и авторизованный Codex CLI
  • Google Chrome для PDF-отчётов

Нет инструментов Apple? Выполните xcode-select --install и завершите установку в системном окне. Python установите привычным пакетным менеджером; AI-доступ описан в инструкции Codex CLI.

Terminal
curl -fsSL https://meetontrack.com/install.sh | bash

Команда скачивает v0.1.9, проверяет SHA-256 и сохраняет настройки и записи. Перед запуском можно прочитать скрипт. При переустановке сначала завершите звонок и закройте Meeting Copilot Capture.

  1. В настройках macOS разрешите Meeting Copilot Capture доступ к микрофону и записи экрана и системного звука.
  2. Выполните ~/.local/bin/meeting-copilot. Откроется интерфейс по адресу http://127.0.0.1:43121.
  3. Выберите нужные репозитории, проведите короткий тестовый звонок и проверьте сохранённое аудио и стенограмму.
Обновления и возможные проблемы

Автообновления внутри приложения в этой beta ещё не включены. Команда устанавливает версию, явно закреплённую в скрипте. Когда выйдет новая проверенная версия и скрипт обновится, завершите звонок, закройте Capture и выполните ту же команду.

При отсутствии зависимости, ошибке загрузки, контрольной суммы или сборки помощников установщик остановится до замены приложения. При переустановке старое приложение и web-файлы сохраняются в резервных копиях. Записи и настройки доставки не удаляются.

Если macOS блокирует запуск, проверьте скачанное приложение в «Конфиденциальность и безопасность». Не отключайте Gatekeeper целиком. При проблеме с доступом к звуку проверьте разрешения именно установленного приложения, затем закройте и откройте его.

Установите beta для Windows.

Windows 11 24H2+, x64. Готовый пакет без сборки и SDK. Требуется установленный и авторизованный Codex CLI. При первой установке скачиваются локальные модели речи (около 1,5 ГБ).

Windows PowerShell
irm https://meetontrack.com/install.ps1 | iex

Техническая beta без Microsoft-подписи. Не отключайте SmartScreen или антивирус. Обновление: завершите звонок, закройте Capture и повторите команду. Записи и настройки сохраняются.
