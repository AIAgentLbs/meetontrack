# Live call map

The default live view presents three simultaneous registers: questions Mike
should ask (preparation and ASK signals), questions addressed to Mike or the
group from the conversation, and risks/objections. The transcript uses about
28% of desktop width; the registers share the remaining space.

Each item has an explicit open / needs clarification / closed status, shown
with both a traffic-light color and text. Unresolved items precede closed
items. Provenance and quoted evidence are available in expandable details.
Prepared items keep their existing checklist state. Live signals receive
meeting-scoped durable status, manual correction, and evidence-checked online
updates. User-entered questions to Copilot are not incoming meeting questions.
An incoming question requires captured speech, an identifiable direction, and
is never inferred from a repository document or an ASK suggestion.

Desktop shows all three registers without switching tabs. Each register scrolls
independently. Small screens put the call map before the optional transcript;
registers stack in reading order. RU and EN labels, keyboard controls, empty
states and long-content overflow are supported.
